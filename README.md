This repository contains Excel Assignment 1, designed to develop practical skills in data analysis and spreadsheet functions using Microsoft Excel.

The assignment uses a sales dataset containing the following fields:

Product ID
Product Name
Brand Name
Price ($)
Quantity
Category

The activities demonstrate how Excel functions can be used to perform calculations, categorize data, analyze products, and extract information from text.
